Overview

What is ClipFlow AI?

ClipFlow AI is a local content generation and upload pipeline for short-form social media videos. It provides a structured workflow for preparing video content and submitting it to TikTok using TikTok's official Content Posting API.

The app is designed so that a user connects their TikTok account, prepares or selects a short-form video, reviews the content and posting details, and then explicitly approves the final publishing action.

⛔ ClipFlow AI does not post content to a TikTok account without the user's explicit authorization. No automatic or background posting occurs.

How It Works

Step-by-step publishing flow

1
Open ClipFlow AI The user launches the application on their device.
2
Connect TikTok account via Login Kit The user authenticates through TikTok's official Login Kit. ClipFlow AI never handles TikTok passwords.
3
Prepare or select video content The user selects or prepares a short-form video file and adds captions or metadata.
4
Review video and posting details The user reviews the video, caption, and posting settings before anything is submitted.
5
Approve the publishing action The user explicitly confirms they want to publish. This is a required user action — the app does not skip this step.
6
Video submitted to TikTok ClipFlow AI submits the approved video to TikTok via the authorized Content Posting API (Direct Post).
TikTok Integration

How TikTok APIs are used

ClipFlow AI integrates with TikTok using TikTok's official developer APIs. All TikTok interactions occur through authorized, documented API endpoints.

Login Kit — Used to authenticate the user's TikTok account securely. ClipFlow AI does not store TikTok passwords. Tokens are stored locally on the user's device and used only to make authorized API calls.

Content Posting API (Direct Post) — Used only after the user has reviewed their content and explicitly approved publishing. The app calls this API once per user-initiated action. No background or scheduled posting is performed.

Requested permissions

user.info.basic
Basic profile information Used to identify the connected TikTok account and display the user's profile name in the app. No profile data is stored on external servers.
video.publish
Publish video to TikTok Used to submit approved video content to the user's TikTok account via the Content Posting API. Only called after explicit user approval.
Privacy & Data

What data ClipFlow AI collects

ClipFlow AI only collects the minimum information needed to operate the TikTok publishing workflow:

  • Basic TikTok account information (username, display name) — used in-app only to confirm the connected account
  • TikTok OAuth tokens — stored locally on the user's device, used only to make authorized API calls
  • Video files and captions provided by the user — processed locally and submitted to TikTok on user approval
  • Basic operational logs for error tracking and troubleshooting

ClipFlow AI does not sell user data. User data is not shared with third parties except as required to operate the TikTok API integration (i.e., submitting content to TikTok on the user's behalf).

User control

Users remain in full control of publishing. The app cannot and does not publish content without the user first reviewing and approving the action. Users can disconnect their TikTok account at any time.
